# Simon Says Game

A fun and interactive Simon Says game created using JavaScript, HTML, and CSS. Challenge your memory and reflexes by repeating the generated color sequences as they progressively get more difficult.

## Features

- **Dynamic Gameplay**: Randomly generated color sequences that increase in complexity.
- **Interactive Design**: Clickable buttons with animations and sound effects.
- **Progressive Difficulty**: The game becomes more challenging as you advance.

## Technologies Used

- **HTML5**: For structuring the game layout.
- **CSS3**: For styling and animations.
- **JavaScript**: For game logic and interactivity.

## Getting Started

Follow these steps to play the Simon Says game on your local machine:

### Prerequisites

- A modern web browser (e.g., Chrome, Firefox, Edge).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nikhilkumar2311/simon-says-game.git
   ```
2. Navigate to the project folder:
   ```bash
   cd simon-says-game
   ```
3. Open the `index.html` file in your browser.

## Usage

- Click the colored buttons in the same order as the game sequence.
- The sequence gets longer with each successful round.
- Challenge yourself to achieve the highest score!

## Project Structure

- `index.html`: Main HTML file.
- `style.css`: Contains all the CSS styles.
- `script.js`: Contains the game logic.
